# 企业微信副驾面板 · 交互设计稿 v2

> 资深 UI/UX 视角重构。改版方向：**重构信息架构 · 以 AI 副驾草稿台为中心 · 专业克制视觉**。
> 商业化定位见 `docs/`（To B 坐席订阅 SaaS，AI 回复副驾为尖刀）。本稿为后续实现依据。

---

## 0. 设计原则

1. **草稿台即主界面** —— 「收消息 → 自动读取 → 手动生成 → 微调 → 发送」是唯一主动线；话术、设置、管理皆为其服务。
2. **一屏一焦点** —— 任一时刻只有一个主操作高亮（生成 / 发送二选一），其余降为幽灵按钮或溢出菜单。
3. **专业克制** —— 单色线性图标、收敛蓝、8pt 网格；零 emoji、零跳色，面向 To B 采购观感。

## 2. 信息架构

```
顶栏    ● 对象选择器▾ ················ 话术  ☰菜单
──────────────────────────────────────────────
上下文条（折叠）  ▸ 已读取 N 条 · 时间   重读
──────────────────────────────────────────────
草稿台（弹性最大区）
  · 草稿编辑框（可改）
  · 微调 chips：更正式 · 更简短 · 换个说法 · ⋯
  · 来源 caption：ⓘ 据 N 条会话 + 知识库
──────────────────────────────────────────────
底部固定条   [ ✈ 确认发送 ]            ⋯
                              （复制 / 存知识库 / 清空）
```

**相对现状的删减：**
- 删除 `[话术] [AI 助手]` 并列模式切换 —— 草稿台即主界面。
- 删除独立状态行 —— 状态点并入对象选择器（`● 企业微信·张三 ▾`）。
- 底部按钮从 7 个压到 **1 主操作 + 1 溢出**。
- 上下文区从常驻 ~100px 折叠为 1 行摘要，垂直空间还给草稿框（解决 420×600 固定窗口高度长期紧张问题）。
- 低频项（刷新 / AI·知识库设置 / 权限引导 / AX 自检 / 快捷键）全部收进 `☰`。

## 3. 主流程：草稿台五状态（自动读取 + 手动生成）

| 状态 | 表现 | 主操作 |
|---|---|---|
| **① 未就绪** | 草稿区替换为引导：`⚠ 需要辅助功能权限` + `[ 去开启权限 ]`（把权限门槛从折叠菜单提到主路径）；无客户端时提示「未检测到企业微信」 | — |
| **② 就绪·未生成** | 切换接管对象 / 检测到新消息 → **自动读取**会话，上下文折叠为一行摘要；草稿框 placeholder「点下方生成，或直接输入…」 | `✦ 生成回复` |
| **③ 生成中** | 草稿区呼吸 / 骨架动画（复用 `_ai_anim_step`），按钮禁用 | 禁用 |
| **④ 已生成（核心态）** | 草稿填充 → 微调 chips 激活 → 来源 caption `ⓘ 据 8 条会话 + 知识库生成` | `✈ 确认发送` |
| **⑤ 微调中** | chip 按下 → 草稿区 loading，chips 禁用；完成后替换草稿 | — |

**发送行为（已定）**：点 `✈ 确认发送` → **直接发送当前草稿**（草稿框本身可编辑，不做二次确认）→ 轻 toast「已发送」→ **清空草稿 + 自动重读会话** → 回到状态 ②，准备下一轮。
> 安全边界保持：AI 不自动发送，发送永远是用户主动点击（人在环中，对齐合规定位）。

## 4. 话术覆盖抽屉（顶栏「话术」唤起）

```
┌────────────────────────────┐
│  话术                  ✕    │   下滑 / 点遮罩 / Esc 关闭
│  〔问候语 ▾〕  🔍 搜索…       │
│ ┌────────────────────────┐ │
│ │ 您好，我是您的专属客服…   │ │
│ │              插入 · 发送 │ │   每卡两动作
│ ├────────────────────────┤ │
│ │ 好的，帮您查一下…         │ │
│ │              插入 · 发送 │ │
│ └────────────────────────┘ │
│  ⊕ 添加     ✎ 管理分组      │   低频管理收底部
└────────────────────────────┘
```

- 顶栏「话术」滑出全高抽屉；遮罩 / 下滑 / `Esc` 关闭。不占主界面常驻空间。
- 每张卡片两动作：**插入**（进草稿框）/ **发送**（直发）。
- **变量话术（补断点）**：点 插入 / 发送 时，若话术含 `{变量}` → 弹轻量填充表单（每变量一栏）→ `render_template_blocks` 渲染后再执行；无变量直接执行。
- **快捷路径**（话术虽降为辅助，速度路径不丢）：
  - `⌘1–9` 不开抽屉，直发上次分组前 9 条；
  - `⌘F` 唤起抽屉并聚焦搜索；
  - `Esc` 关抽屉 / 清空。

## 5. 边界与反馈

| 场景 | 处理 |
|---|---|
| 空话术分组 | 卡片区占位「该分组暂无话术，⊕ 添加一条」 |
| 知识库未启用 | 来源 caption 显示「仅据会话生成 · 启用知识库」可点跳设置（替代现紫色 KB 行） |
| 读取失败 / AI 超时 | 草稿区内联错误条 + 「重试」，**不弹打断式弹窗** |
| 反馈机制 | 统一内联 + 轻 toast；移除遮挡式 warning 弹窗（破坏性操作除外） |
