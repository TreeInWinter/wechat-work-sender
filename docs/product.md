# 产品文档

**产品名称：** 企业微信快捷发送面板  
**版本：** 1.0  
**日期：** 2026-05-20

---

## 1. 产品概述

企业微信快捷发送面板是一款 macOS 桌面辅助工具，专为需要在企业微信中高频发送固定话术的场景设计。面板自动贴合企业微信右侧，随其移动和缩放，做到「始终在手边，不挡视线」。

### 目标用户

- **客服人员**：每天重复发送相同的问候语、回复模板、结束语
- **销售人员**：需要在多个聊天窗口快速发送产品介绍、促销信息
- **运营人员**：批量跟进用户，需要快速复用沟通模板

### 核心价值

| 痛点 | 解决方案 |
|------|----------|
| 重复打字耗时 | 一键发送预设话术，< 0.5 秒完成 |
| 复制粘贴多步操作 | 点击卡片直接发出，无需切换窗口 |
| 话术分散难管理 | 分组管理，随时增删，本地持久化 |
| 不知道聊天说了什么 | 一键读取当前聊天最近 30 条消息 |

---

## 2. 功能清单

### 2.1 话术快捷发送

**核心交互：**
- 话术按分组展示为卡片列表，每张卡片右侧有「发送」按钮
- 点击「发送」→ 消息直接发到当前企业微信聊天窗口
- 点击卡片本体 → 选中（高亮），不触发发送

**话术管理：**
- 新建分组、切换分组
- 添加话术、删除话术
- 所有变更实时保存

### 2.2 自定义消息发送

底部文本框可输入任意内容，点击「发送自定义消息」直接发出，发送后自动清空。

### 2.3 读取聊天内容

点击「📋 读取聊天内容」，读取企业微信当前聊天窗口的最近 30 条消息，在弹窗中展示，包含时间戳和消息正文。

### 2.4 窗口贴合与跟随

- 启动时自动定位到企业微信右侧，高度与企业微信对齐
- 企业微信移动、缩放时，面板 100ms 内同步跟随
- 企业微信高度变化时，面板高度同步调整，上下边缘始终对齐

### 2.5 状态感知

- 顶部状态栏实时显示企业微信连接状态（绿点/红点）
- 发送成功、失败、无聊天窗口均有即时反馈

## 3. 用户体验设计

### 3.1 视觉设计

- 主色：企业微信品牌蓝 `#1677FF`
- 卡片：白底圆角，选中时浅蓝高亮
- 字号：12-13px，PingFang SC
- 深色模式自动跟随系统

### 3.2 交互原则

- **单步完成**：发送话术只需一次点击
- **状态可见**：发送结果即时反映在状态栏
- **不打扰**：面板置顶但不阻挡企业微信操作区域

### 3.3 前提条件

使用前需满足：
1. 企业微信桌面版已打开
2. 已在企业微信中点开一个聊天窗口
3. 已在系统设置中授予辅助功能权限

## 4. 使用场景

### 场景 A：客服快速应答

小王是客服，每天要回复 200+ 条消息。她把常用的「您好」「稍等」「感谢您的反馈」存在面板里，对话来了直接点发，每条消息节省 10 秒，一天节省 30 分钟。

### 场景 B：销售跟进

老李在跟进 50 个客户，每人需要发送相似但不完全相同的回复。他用自定义消息框针对每个客户微调文字，不需要来回切换应用。

### 场景 C：了解对话上下文

接手同事转来的对话，不知道之前聊了什么，点「读取聊天内容」，30 条消息摘要一目了然。

---

## 5. 非功能需求

| 指标 | 目标 |
|------|------|
| 发送延迟 | < 0.5 秒（激活 + 聚焦 + 粘贴 + 发送）|
| 窗口跟随延迟 | < 100ms |
| 内存占用 | < 50MB |
| 启动时间 | < 3 秒 |
| 兼容性 | macOS 10.15+，企业微信 4.x |

---

## 6. 已知限制

- 仅支持 macOS，不支持 Windows/Linux
- 依赖辅助功能权限，企业安全策略可能限制授权
- 只能操作当前选中的聊天窗口，不支持多窗口同时发送
- 聊天历史读取受限于企业微信 AX 树暴露的内容（当前屏幕可见消息）
