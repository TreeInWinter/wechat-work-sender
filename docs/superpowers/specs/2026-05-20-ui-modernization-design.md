## 背景

当前 GUI 使用原生 tkinter，在 macOS 上存在以下问题：
- 控件无圆角、无阴影，视觉陈旧
- 按钮颜色混乱（绿/蓝/紫三色并存），无统一主题
- 不支持 macOS 深色/浅色模式自动切换
- 话术列表需要"选中 → 点发送"两步操作，效率低

**目标：** 迁移到 CustomTkinter，统一品牌蓝配色，话术改为卡片一键发送。

---

## 技术方案

### 框架替换

| 旧 | 新 |
|----|----|
| `tkinter` / `ttk` | `customtkinter` |
| `tk.Tk` | `ctk.CTk` |
| `tk.Button` | `ctk.CTkButton` |
| `tk.Frame` | `ctk.CTkFrame` |
| `tk.Text` | `ctk.CTkTextbox` |
| `ttk.Combobox` | `ctk.CTkOptionMenu` |
| `ttk.Scrollbar` | `ctk.CTkScrollableFrame`（内置滚动）|
| `tk.Label` | `ctk.CTkLabel` |

CustomTkinter 安装：
```bash
uv pip install customtkinter
```

## 交互设计

### 话术卡片

- **点击卡片「发送」按钮** → 直接发送该话术（原双击逻辑保留为备选）
- **点击卡片本体** → 选中（高亮边框），不发送
- **选中态** → 背景 `#e6f0ff`，左侧蓝色竖条，发送按钮变实心

### 状态栏圆点

- 企业微信运行中 → 绿色圆点 `#52c41a` + "企业微信快捷发送"
- 未运行 → 红色圆点 `#ff4d4f` + 文字变灰
- 检测中 → 橙色圆点 `#faad14`

### 深色模式

CustomTkinter 自动跟随 macOS 系统外观。主色 `#1677FF` 在深色模式下保持，背景和卡片颜色由框架自动处理。
