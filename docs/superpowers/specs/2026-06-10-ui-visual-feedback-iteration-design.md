# UI 观感与交互迭代（P0 收尾 + P2 视觉 + 调研增补）· 设计稿

> 2026-06-10。基于 `docs/ui-interaction-spec-v2.md`（交互稿 v2）与业内调研定稿。
> 范围：v2 P0 剩余结构项 + P2 视觉规范化 + 3 项调研增补。
> 出界：P1 自动读取状态机、话术抽屉、变量填充表单（下轮）；深色模式、动效系统。

## 调研结论（摘要）

- **坐席 AI 副驾**（Intercom Fin Copilot / Zendesk Agent Copilot / 沃丰智能坐席助手）：AI 草稿
  填充可编辑框、人审后发送是行业共识，v2「草稿台即主界面」方向正确；业内普遍带
  **来源可追溯标注**与「AI 生成请审核」轻提示。
- **AI 写作助手**（Grammarly / Notion AI）：tone chips + 自定义指令已对齐；但它们的改写
  **可撤销 / 可对比 / 可重生成**，当前实现是破坏性替换——本轮补齐撤销。
- **快捷话术工具**（Raycast Snippets / TextExpander）：搜索优先 + 键盘直达；当前搜索只搜
  当前分组——本轮改为跨分组。
- **Copilot UX 通则**：输出当作协作迭代稿；错误内联呈现不打断；反馈走轻 toast。

## A. 结构收尾（v2 P0 剩余）

### A1 移除双模式切换行
- 删除 `mode_frame`（「话术 / AI 助手」并列按钮行），`_switch_mode` 改由顶栏入口驱动。
- 顶栏右侧（⋯ 左）新增「话术」文字按钮；话术页时同位置变「草稿台」可切回。
- 草稿台为默认主界面（已是）。

### A2 状态点并入对象选择器
- 顶栏左侧 = `●`（状态点）+ IM 选择器胶囊；删除粗体 `status_label` 状态文字。
- `status_label` 现承担约 20 处发送/状态反馈 → 统一改走 toast（C1）；保留隐藏的
  `status_label` 兼容引用（不进布局）或将 `_set_status_text` 收敛为 toast/摘要行调用。
- 状态详情（如「需要辅助功能权限」）：异常态用状态点颜色 + tooltip/上下文摘要行呈现。

### A3 上下文区折叠
- `ai_context_box`（常驻 ~100px）→ 单行摘要条：`▸ 已读取 N 条 · HH:MM    重读`。
- 点击摘要行展开/收起完整上下文（展开时高度 ~120px）；默认收起。
- 释放高度给草稿框（`ai_reply_box` expand）。

## B. 视觉规范化（v2 P2）

### B1 色彩 Token
| Token | 现值 | 目标 |
|---|---|---|
| PRIMARY | `#4F46E5` | `#2B5CE6` |
| PRIMARY_H | `#4338CA` | `#1E47C0` |
| ACCENT_SOFT | `#EEF0FF` | `#EAF0FD` |
| DOT_OK / DOT_WAIT / DOT_ERR | `#22C55E / #F59E0B / #EF4444` | `#34C759 / #8F959E / #FF3B30`（检测中=灰） |
- KB 状态行去彩色底（蓝/绿块）→ 中性 SURFACE + 1px 描边，仅文字着色。

### B2 emoji → 单色线性符号
- 替换全部 `➕🗑️💾📂📗☁️🩺✅❌⚙️` 等 emoji：用细线 unicode（`⊕ ✎ ✈ ⌫ ⓘ`）或纯文字。
- 4 处 CTkToplevel 弹窗的饱和色标题栏（`fg_color=PRIMARY` header）→ 近白 + 1px 底部分隔线。

### B3 字号 / 圆角 / 间距
- 字号三级：标题 13 / 正文 12 / 辅助 11（PingFang SC）。
- 圆角：按钮 8、输入框 10。间距对齐 8pt 网格（4/8/12/16）。

## C. 反馈体系（v2 P2）

### C1 轻 toast
- 自绘浮层（主窗内底部居中，深色半透明圆角条，1.8s 自动消失，after 驱动）。
- 承接「已发送 / 已复制 / 已存入知识库 / 已重读」等成功反馈。

### C2 内联错误条
- 草稿框上方红色细条：`✕ <错误摘要> [重试]`；重试绑定上次失败的操作。
- 替换非破坏性 `_show_warning` 调用（读取失败 / AI 超时 / 改写失败 / 空内容提示等）。
- 破坏性确认（删除分组/话术）保留弹窗（`_ask_yesno`）。

## D. 调研增补

### D1 改写可撤销
- `self._draft_history: list[str]` 栈；`_ai_refine` / `_ai_regenerate` 成功替换草稿前压栈。
- 改写完成后出现「撤销」轻按钮（chips 行尾或状态行旁）；⌘Z 绑定；逐级回退；
  手动编辑或发送清空栈。

### D2 AI 生成轻标识（来源 caption）
- 生成/改写完成后草稿框下方 caption：`ⓘ 据 N 条会话生成 · 发送前请确认`；
  启用知识库时为 `ⓘ 据 N 条会话 + 知识库生成 · 发送前请确认`。
- 用户清空/发送后隐藏；手动编辑保留（仍是 AI 底稿）。

### D3 跨分组搜索
- 搜索框非空 → 检索全部分组；卡片显示来源分组标签（右上角弱文字）。
- 清空搜索 → 恢复当前分组视图。⌘1-9 按可见顺序直发（既有行为不变）。

## 实施顺序与验证

B（换肤）→ A（结构）→ C（反馈）→ D（增补）。每步：
`.venv/bin/python -m py_compile gui_panel.py` + 启动冒烟（手动/截图确认布局不破）。
窗口仍为 420×600 固定；`resizable(False, False)` 不变。
