# BlockEditor WYSIWYG 重设计文档

**日期：** 2026-05-21  
**分支：** feature/rich-text  
**状态：** 待实现

---

## 背景

现有 `BlockEditor` 是功能性但视觉简陋的块列表，块之间缺乏预览感，图片只显示文件名。目标是改造为**内联画布**风格——文字块始终可编辑，图片块显示真实缩略图，整体看起来像一个消息草稿编辑器。

---

## 设计方案：内联画布（B 方案）

### 整体布局

```
┌─────────────────────────────────────┐  ← CTkToplevel 520×500
│  编辑话术              [取消] [确认]  │  ← 蓝色标题栏
├─────────────────────────────────────┤
│  ┌─────────────────────────────┐    │
│  │ 文字  ↑ ↓ 🗑               │    │  ← 活跃块：蓝色边框
│  │ 您好！以下是操作步骤：|     │    │
│  └─────────────────────────────┘    │
│  ┌─────────────────────────────┐    │
│  │ 图片  ↑ ↓ 🗑               │    │  ← 图片块：橙色标签条
│  │ [缩略图72×54] step1.png     │    │
│  │                 替换图片     │    │
│  └─────────────────────────────┘    │
│  ┌─────────────────────────────┐    │
│  │ 文字  ↑  — 🗑               │    │  ← 末尾块：↓ 按钮隐藏

│  └─────────────────────────────┘    │
│                                     │

```

## 组件规范

### 块容器（Block Row）

每个块是一个 `ctk.CTkFrame`，内含：
- **标签条**（高 24px）：左侧「文字」/「图片」标签，右侧 ↑↓🗑 按钮
  - 文字块标签条：`bg=#e6f0ff`，标签颜色 `#1677FF`
  - 图片块标签条：`bg=#fff8f0`，标签颜色 `#fa8c16`
  - 非活跃块标签条：`bg=#f8f8f8`，标签颜色 `#999`
- **内容区**：文字块放 CTkTextbox，图片块放缩略图+元信息

**活跃态**（焦点块）：`border_color="#1677FF"`, `border_width=2`  
**静默态**：`border_color="#e8e8e8"`, `border_width=1.5`

### 文字块

```python
ctk.CTkTextbox(
    row, height=72, corner_radius=0, border_width=0,
    font=ctk.CTkFont(family="PingFang SC", size=12),
)
```

- 焦点事件：`<FocusIn>` 触发外层容器切换到活跃态
- `<FocusOut>` 同步内容到 `self.blocks[i]["content"]`

### 图片块

使用 **Pillow** 生成缩略图（72×54px，保持宽高比，居中裁剪）：

```python
from PIL import Image as PILImage
import customtkinter as ctk

def make_thumbnail(path: str, size=(72, 54)) -> ctk.CTkImage:
    img = PILImage.open(path)
    img.thumbnail((size[0]*2, size[1]*2), PILImage.LANCZOS)
    return ctk.CTkImage(light_image=img, dark_image=img, size=size)
```

若路径不存在或 PIL 加载失败，显示占位图（蓝色渐变背景 + 🖼 emoji）。

图片块内容区布局：
- 左：CTkLabel 显示缩略图（72×54）
- 右上：文件名（11px, `#333`）
- 右中：`宽 × 高 · 文件大小`（10px, `#999`）
- 右下：「替换图片」文字按钮（10px, `#1677FF`，点击重新选文件）

### 添加区

底部两个虚线按钮，始终可见：
- `border_width=1.5, border_color="#bbd6ff"` → 添加文字（蓝）
- `border_width=1.5, border_color="#ffd591"` → 添加图片（橙）

## 交互细节

| 操作 | 行为 |
|------|------|
| 点击文字块内容区 | 文字块获得焦点，边框变蓝 |
| 点击文字块外任意处 | 失焦，边框变灰，内容同步到 blocks |
| 点击「替换图片」| 打开 filedialog，选择新文件后更新缩略图 |
| ↑ / ↓ 按钮 | 块交换位置，重新渲染，保持当前焦点块激活态 |
| 🗑 按钮 | 直接删除块，无需确认；删到只剩1块时🗑按钮仍可点，但确认时如内容为空不关闭 |
| 确认（内容为空） | 不关闭，保持当前状态 |
| 取消 | 直接关闭，不保存 |

## 验证方式

1. 新建含文字+图片+文字的话术，图片显示真实缩略图
2. 修改文字块内容后点确认，卡片展示更新
3. 上移/下移块，顺序正确
4. 删除块后剩余块正常显示
5. 图片文件不存在时显示占位图而非崩溃
6. 旧纯文本话术编辑时正常打开（向后兼容）
