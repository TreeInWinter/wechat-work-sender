# 使用手册

**企业微信快捷发送面板 v1.0**  
**适用平台：** macOS 10.15+

---

## 一、安装与启动

### 1.1 安装依赖

```bash
# 进入项目目录
cd wechat_work_sender

# 安装 Python 依赖
uv pip install pyobjc-framework-Cocoa \
               pyobjc-framework-Quartz \
               pyobjc-framework-ApplicationServices \
               customtkinter
```

### 1.2 授予辅助功能权限

首次运行前必须完成授权，否则无法读取企业微信窗口信息。

1. 打开「系统设置」→「隐私与安全性」→「辅助功能」
2. 点击 `+` 按钮，添加你的终端应用（Terminal / iTerm2 / VS Code 等）
3. 确保开关处于**开启**状态

> 如果使用 IDE（如 VS Code）运行，需要授权 VS Code，而非终端。

### 1.3 启动

```bash
# 方式一：直接运行
python gui_panel.py

# 方式二：使用启动脚本
./start.sh
```

**启动前请确保：**
- 企业微信桌面版已打开
- 已在企业微信中点开一个聊天窗口

## 三、基本操作

### 3.1 发送话术

1. 在分组下拉框中选择需要的分组（如「问候语」）
2. 在列表中找到目标话术
3. 点击话术卡片右侧的 **「发送」** 按钮
4. 消息即刻发送到企业微信当前聊天窗口

> **提示：** 点击卡片本体可选中（蓝色高亮），不触发发送。

---

### 3.2 发送自定义消息

1. 在底部输入框中输入消息内容
2. 点击 **「发送自定义消息」**
3. 消息发出后输入框自动清空

---

### 3.3 添加话术

1. 切换到需要添加话术的分组
2. 点击 **「➕ 添加话术」**
3. 在弹出的输入框中输入话术内容，点击确认
4. 新话术出现在当前分组列表末尾

---

### 3.4 删除话术

1. 点击要删除的话术卡片（使其高亮选中）
2. 点击 **「🗑️ 删除选中」**
3. 确认删除

---

### 3.5 新建分组

1. 点击右上角 **「+ 新分组」**
2. 在弹出的输入框中输入分组名称，点击确认
3. 自动切换到新分组

---

### 3.6 读取聊天内容

1. 确保企业微信中已打开一个聊天窗口
2. 点击 **「📋 读取聊天内容」**
3. 弹窗展示最近 30 条消息，包含时间戳和正文

## 四、常见问题

**Q：点击「发送」没有反应，消息没有发出**

A：依次检查：
1. 企业微信是否已打开？（状态栏是否显示绿点）
2. 企业微信中是否选中了一个聊天窗口？（非会话列表页面）
3. 辅助功能权限是否已授予当前终端 / IDE？

---

**Q：出现「请先在企业微信中选中聊天窗口」的提示**

A：需要先在企业微信中点击一个具体的聊天对话，再回来点发送。

---

**Q：弹出框（新建分组、添加话术）看不到**

A：面板窗口置顶可能遮挡弹出框。弹出框出现时，面板会短暂退后，稍等 0.5 秒即可看到输入框。

---

**Q：读取聊天内容显示「未读取到消息」**

A：需要在企业微信中点开一个聊天窗口，不能停留在会话列表页面。

---

**Q：面板没有贴合到企业微信右侧**

A：检查企业微信是否最小化或被其他窗口遮挡。面板每 100ms 读取一次企业微信坐标，稍等片刻即可自动对齐。

---

**Q：macOS 切换深色模式后面板显示异常**

A：重启面板即可，`python gui_panel.py` 重新启动后会自动适配当前系统外观。

## 六、数据说明

所有话术数据保存在 `phrases.json` 文件中，与程序同目录。

- **自动保存**：每次添加、删除话术或新建分组，都会即时写入文件
- **手动编辑**：可直接编辑 `phrases.json` 批量导入话术，重启程序后生效
- **备份**：建议定期备份 `phrases.json`，防止意外丢失

`phrases.json` 格式：

```json
{
  "分组名称": [
    "话术一",
    "话术二"
  ]
}
```
